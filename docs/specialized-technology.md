# Specialized Technology

## Chosen technology
Computer vision: deep learning for medical image classification, using
Convolutional Neural Networks (CNNs) and Vision Transformers (ViTs),
with confidence calibration and Grad-CAM explainability.

## Why this technology
It can classify chest X-rays as cardiomegaly or normal, show a heatmap of
where the model looked, and give a calibrated confidence score so that
uncertain cases can be flagged for a doctor to review.
