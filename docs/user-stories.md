# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a medical officer, I want upload a chest X-ray and see whether it is shows cardiomegly with a confidence score, so that I can decide if the case needs closer attention. (FR1, FR2, FR3)
2. As a radiologist, I want to see a heatmap of the regions the model focused on, so that I can check whether the prediction makes clinical sense. (FR4)
3. As a medical officer, I want the system to flag prediction if it is unsure with the result and show the measured cardiothoracic ratio (CTR), so that I know which cases need review by a radiologist. (FR5, FR6)
